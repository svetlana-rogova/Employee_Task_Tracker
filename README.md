# Employee task tracker
## Описание:
Проект представляет собой систему управления задачами сотрудников. Позволяет создавать, распределять и отслеживать 
выполнение рабочих заданий в реальном времени для определенного круга лиц. 
Идея заключается в том, что руководители групп и модератор управляют задачами, а другие сотрудники могут видеть
крайний срок сдачи работы. 
## Функционал:
- Регистрация, авторизация и профиль пользователей
- CRUD-операции для задач и сотрудников через Django REST Framework ViewSet
- Вывод списка важных задач со списком возможных кандидатов на выполнение
- Вывод списка сотрудников с активными задачами
- Удаление и изменение задач только для модератора и владельца задачи
- Пагинация списка задач
- Валидация бизнес-логики задач
## Установка и использование:
1. Откройте PyCharm
2. Клонируйте репозиторий:
```
git clone https://github.com/svetlana-rogova/Employee_Task_Tracker
```
3. Для запуска проекта используется docker-compose.yml:
```
docker compose up --build
```

## Структура проекта:

- task/ — логика задач
- users/ — пользователи
- config/ — настройки проекта

## Тестирование:
Все тесты лежат в модуле task/tests.py, имена функций начинаются с test_.
Запустить тесты можно через команду pytest в терминале:
```
python manage.py test
```

Проверить покрытие можно через команду:
```
coverage report
```
## Права доступа:

- Неавторизованные пользователи имеют доступ только к просмотру списка задач
- Авторизованные пользователи могут создавать свои задачи, смотреть список важных задач и список сотрудников
- Редактирование и удаление задач доступно только модератору и владельцу


## Бизнес-логика:

- При добавлении новой задачи срок ее выполнения не может быть в прошлом
- Задача не может быть родительской сама для себя
- Если у задачи статус "в работе", то она не может оставаться без исполнителя

## API:

- POST /users/register/
- POST /users/login/

- GET /employee/ — список сотрудников
- GET /employee/busy/ — список сотрудников с активными задачами
- POST /employee/ — добавление сотрудника
- PUT /employee/{id}/ — обновление сотрудника
- DELETE /employee/{id}/ — удаление сотрудника
- GET /task/ — список задач
- GET /task/important/ — список важных задач
- POST /task/ — добавление задачи
- PUT /task/{id}/ — обновление задачи
- DELETE /task/{id}/ — удаление задачи
